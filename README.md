# 🛒 E-Commerce Order Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **E-Commerce Order Dashboard** built using **Microsoft Power BI**. The dashboard provides a comprehensive view of e-commerce sales and order performance, helping users analyze sales trends, customer behavior, product performance, and overall business performance.

The goal of this project is to transform raw e-commerce order data into meaningful and interactive business insights.

---

## 🎯 Project Objectives

* Analyze overall e-commerce sales and order performance
* Identify top-performing products and categories
* Analyze sales trends over time
* Understand customer purchasing patterns
* Compare sales performance across different regions
* Track key business performance indicators (KPIs)
* Create an interactive dashboard for data-driven decision making

---

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Data Visualization**
* **Microsoft Excel / CSV** – Data source

---

## 📌 Key KPIs

The dashboard focuses on important e-commerce metrics such as:

* 💰 Total Sales
* 📦 Total Orders
* 👥 Total Customers
* 🛍️ Total Products
* 📈 Sales Growth
* 🏆 Top-Performing Products
* 🌎 Regional Sales Performance

---

## 📊 Dashboard Features

### Sales Analysis

* Overall sales performance
* Sales trends over time
* Monthly/yearly sales comparison
* Category-wise sales analysis

### Product Analysis

* Top-selling products
* Product/category performance
* Identification of high-performing and low-performing products

### Customer Analysis

* Customer purchasing behavior
* Customer contribution to sales
* Order and sales analysis

### Regional Analysis

* Sales performance by region
* Comparison of different geographical areas

### Interactive Filters

The dashboard includes interactive filters/slicers that allow users to analyze the data based on different dimensions such as:

* Date
* Category
* Product
* Region
* Customer
